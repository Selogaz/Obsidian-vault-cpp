Подготовь утреннюю сводку для менеджера передачи клиентского проекта. Источник — обезличенная выборка journal.tsv. Дата среза приходит от пользователя. Сначала назови план. Для каждого item, известного к концу этой даты, выбери статус open, waiting, cancelled или done по последней доступной записи. Сохрани в result.json объект, где ключ — item, значение — статус. В чате выведи основание с датой и предложи один следующий шаг для менеджера, если он нужен. Не выводи факт получения доступа из факта закрытия задачи. Проверь результат командой python3 eval.py ДАТА, при расхождении перечитай журнал и исправь результат. Менять можно только result.json.
