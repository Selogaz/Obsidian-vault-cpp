# Description

Короткий проект по итогам визита к неврологу (август 2026): пройти назначенный курс, собрать данные дневника головной боли и через 3 месяца принять решение о дальнейшей тактике — на цифрах, а не на ощущениях.

# 🟩 Визит к неврологу

Назначения:
- **Сермион (ницерголин)** — 3 месяца по 2 таблетки в день (куплен, курс начат)
- **Суматриптан 100 мг** — купирование приступа мигрени
- По протрузиям шеи (C3–C4, см. [[медицинский брифинг для врача]]): **ортопедическая подушка** и **воротник Шанца** (куплены)

Врач сам отметил, что современно мигрень профилактируют антидепрессантами, но он «действует по-старинке».

# 🟩 Разбор назначений

**Суматриптан — доказательный стандарт купирования.** Правила приёма:
- принимать как можно раньше в приступе (в фазе боли, не в ауре); можно повторить через 2 часа
- **не чаще 8–9 дней в месяц** — иначе риск абузусной (лекарственно-индуцированной) головной боли
- **не принимать на пике давления**: триптаны кратковременно повышают АД, а в анамнезе пароксизмы до 170 при фоне 120/80 — сначала успокоиться/снизить, потом триптан

**Сермион — вне современных рекомендаций по мигрени.** EMA ещё в 2013 исключила у ницерголина показание «профилактика мигрени» (польза не доказана). Решение: курс всё равно пропить, риски за 3 месяца минимальны (фиброз — осложнение многолетнего приёма, для ницерголина казуистика). На что смотреть:
- побочка: снижение АД, головокружение при вставании (особенно в начале курса); осторожнее с алкоголем
- «сермион полезен при скачках давления» — не работает: он снижает давление постоянно, а не срезает пики
- с суматриптаном совместим: запрет «триптан + эрготы» касается сосудосуживающих (эрготамин, ДГЭ), ницерголин — вазодилататор

**Современная профилактика мигрени** (актуально, если ≥4 мигренозных дней/мес или приступы инвалидизирующие):
- первая линия: бета-блокаторы (пропранолол, метопролол), кандесартан, амитриптилин/венлафаксин, топирамат
- при частой/хронической мигрени: моноклональные антитела к CGRP (эренумаб, фреманезумаб)
- **пропранолол или кандесартан закрыли бы одним препаратом и мигрень, и скачки АД** — аргумент для следующего врача, если дневник покажет частые приступы

**Воротник Шанца** — режим по назначению невролога: **15 мин/день**, не увеличивать самовольно. Сильная тяга носить дольше = сигнал хронической перегрузки мышц шеи, а не повод наращивать пассивную разгрузку (спираль: больше воротника → слабее мышцы → сильнее тяга). Устойчивая замена — активная линия: ЛФК на глубокие сгибатели шеи (спросить комплекс/направление у невролога), перерывы в сидении, высота монитора. Подушка — постоянно.

**Вода/плавание** — «правильная» версия разгрузки шеи (снимает осевую нагрузку + мягкая работа мышц), при протрузиях рекомендуется. Правила: не плавать брассом с головой над водой (переразгибание шеи), не нырять головой вниз. Напряжение шеи — известный триггер мигрени, так что дни на море — эксперимент для дневника головной боли.

# 🟦 План на курс (до ~22.11.2026)

- [ ] Дневник головной боли в daily-заметках: дни с мигренью, интенсивность, приём суматриптана
- [ ] Курс сермиона 2 таб/день; отмечать головокружение/гипотензию
- [ ] Домашние замеры АД ~2 недели (утро/вечер, сидя, после 5 мин покоя) — заодно закрывает пункт «ортостатика/лог АД» из [[медицинский брифинг для врача|брифинга]]
- [ ] Подушка постоянно, воротник Шанца — 15 мин/день (если хочется дольше — сначала спросить невролога)
- [ ] Спросить у невролога ЛФК для шеи (глубокие сгибатели) — активная замена воротнику
- [ ] На море: плавание без брасса «с головой над водой», не нырять головой вниз; отмечать в дневнике, как ведёт себя голова
- [ ] По итогу: посчитать мигренозные дни/мес → если ≥4 или приступы тяжёлые — цефалголог (клиника головной боли, работают по международным протоколам) с дневником на руках

# Критерии завершения

Курс пройден, дневник собран, решение принято: либо «мигрень редкая, суматриптан по требованию — достаточно», либо переход на доказательную профилактику у цефалголога.
