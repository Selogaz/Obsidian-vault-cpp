Действия, которые восстанавливают энергию и проходят тест из [[легитимизация отдыха]]: после них хочется работать, а не ещё больше суррогата.

## Критерий

Единственный тест: **настоящий отдых заканчивается сам** — после него появляется желание взяться за дело. После суррогата хочется ещё суррогата.

## Список

### Физическое восстановление
- **Сон** — консолидация памяти, фаза учебного цикла
- **Спорт / плавание** — физическая разрядка, переключение
- **Душ / ванна** — активация рассеянного мышления

### Переключение без экрана
- **Прогулка** (пешком)
- **Еда без экрана** — пауза вместо фонового потребления
- **Рисование**
- **Игра на музыкальном инструменте** (знакомые пьесы — без когнитивной нагрузки)

### Социальное
- **Живой разговор** с близкими
- **Помощь в несложном деле** — переключение без достиженчества

### Рассеянное мышление
- **Музыка без слов**
- **Чтение расслабляющей книги**
- **Поездка в качестве пассажира**

### Плановый отдых
- **Пустой день в неделю** — по расписанию, а не по обрушению
- **Вечер после N часов работы** — назначенный отдых как выполнение плана

## Что не отдых

Суррогат — скроллинг ленты, вдохновляющие видео ночью — не восстанавливает. Потребность остаётся, психика ищет новую лазейку. Критерий тот же: после такого хочется ещё, а не работать.
