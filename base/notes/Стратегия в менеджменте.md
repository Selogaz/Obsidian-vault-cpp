# Определение

Стратегия - результат [[определение стратегирования|стратегирования]]. Документ, который содержит замысел и верхнеуровневый (крупными мазками) план по достижению целей.

# Стратегия и стратегирование

Стратегия отвечает на вопрос "Что делать?"
Стратегирование отвечает на вопрос "Как думать, чтобы понять, что делать?". Некая мета-позиция по отношению к стратегии.
