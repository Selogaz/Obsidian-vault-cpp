С 7 июля 2026 Fable 5 недоступен в подписке; работа продолжается на Sonnet 5 и Opus 4.8. Разница не в том, чего они не могут, а в том, что Fable делал сам, а их надо просить явно — полный список механизмов с готовыми формулировками: [[что Fable делал сам — проси явно]]. Главный уравнитель — промт с циклом верификации и проверяемым Definition of Done, а не модель ([[чем определяется качество верстки]]).

Карта промтов:

| Задача | Промт | Модель |
|---|---|---|
| Новая фича, неясные требования | [[промт для планирования фичи]] | Opus 4.8 план → Sonnet 5 код |
| Верстка из Figma | [[промт для верстки из Figma (универсальный)]]; для Байт Транзит — [[промт для верстки bite-transit(асташко)]] | Sonnet 5 xhigh |
| Ревью кода | [[промт для возобновляемого ревью кода\|промт для ревью кода v2]] (v1: [[промт для ревью кода]]) | Sonnet 5 батчи → Opus 4.8 вердикты |
| Баг | [[промт для дебага]] | Sonnet 5; Opus 4.8, если причина не даётся |
| Тесты | [[промт для написания тестов]] | Sonnet 5 |

Правила вокруг промтов:

- Выбор модели и режимов — [[выбор модели по типу задачи]] (сейчас Max 5x, с августа Pro — правила заточены под Pro).
- Лимиты и продолжение после обрыва сессии — [[токен-гигиена и возобновляемость]].
- Короткие англоязычные шаблоны — [[AI prompts]].
