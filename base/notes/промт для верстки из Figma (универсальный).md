Параметризованная версия проверенного [[промт для верстки bite-transit(асташко)]]. Рабочим его делает не привязка к проекту, а четыре механизма: единственный источник истины (конкретные узлы Figma, не весь файл), обязательный цикл сверки скриншотов до неразличимости, Definition of Done с доказательствами (grep по диффу + линты) и скоуп-забор «только эта секция». Под новый проект заполни плейсхолдеры `{…}` один раз и сохрани готовый промт в проекте (например, docs/prompts/верстка.md).

Практика: одна секция = одна сессия; модель — Sonnet 5, effort xhigh; каждые 3–4 секции — отдельный ревью-проход на Opus 4.8 ([[выбор модели по типу задачи]]).

> Сверстай секцию «{СЕКЦИЯ}» страницы «{СТРАНИЦА}» проекта {ПРОЕКТ} пиксель-в-пиксель по макету Figma.
>
> Перед началом прочитай и считай обязательными: {ФАЙЛЫ ПРАВИЛ: CLAUDE.md, стайлгайд, план/роадмап, заметки по странице}.
>
> Источник истины — Figma {FIGMA_FILE_KEY}: десктоп — узел {УЗЕЛ_ДЕСКТОП} ({ШИРИНА}px), мобайл — узел {УЗЕЛ_МОБАЙЛ} ({ШИРИНА}px). Работай ТОЛЬКО с этими узлами — остальное в файле может быть устаревшими итерациями. Секцию изучай визуально (скриншот узла) + design-context для точных размеров/цветов/шрифтов. Сырые метаданные канваса не реверсить.
>
> Порядок работы:
> 1. Отрендери секцию из макета. Выпиши структуру, ВСЕ тексты дословно (ничего не сочинять), размеры, цвета. Сверь значения со стайлгайдом — в коде только переменные/токены из {ПУТЬ К ПЕРЕМЕННЫМ}, хардкод значений запрещён.
> 2. Ассеты в {ПУТЬ К КАРТИНКАМ}: контентные ×2, декоративные ×1, иконки — SVG с currentColor; свечения, тени и ореолы — на CSS, не растром.
> 3. Разметка: {ПУТЬ К ШАБЛОНАМ}. Максимально переиспользуй существующие компоненты ({ГДЕ ЛЕЖАТ КОМПОНЕНТЫ}), прежде чем писать новые. Именование: {СОГЛАШЕНИЯ: БЭМ, запреты вложенности}.
> 4. Стили: ОДИН файл {ПУТЬ К ФАЙЛУ СТИЛЕЙ СЕКЦИИ}. Правила: {ЕДИНИЦЫ И ЗАПРЕТЫ: rem/em вместо px, height → min-height, position:absolute только для декора}.
> 5. ОБЯЗАТЕЛЬНЫЙ цикл сверки (не пропускать): {КОМАНДА ЗАПУСКА} → скриншот секции с {ЛОКАЛЬНЫЙ АДРЕС} headless-браузером → сравни со скриншотом узла Figma → перечисли конкретные расхождения (отступы, кегль, межстрочка, цвета, выравнивание, радиусы) → исправь → повтори. Останавливайся только когда расхождения неразличимы на глаз; обычно нужно 2–3 круга.
> 6. Линты: {КОМАНДЫ ЛИНТОВ} — чисто.
>
> Definition of Done — отчитывайся только с доказательствами по каждому пункту:
> - финальная пара скриншотов (Figma / локальный) совпадает — приложи обе;
> - тексты дословно из макета;
> - grep по твоему диффу: нет {ЗАПРЕЩЁННЫЕ ПАТТЕРНЫ: голых px и hex вне файла переменных, height, inline style, запрещённых классов};
> - линты зелёные, {КОМАНДА ПРОД-СБОРКИ} зелёная.
>
> Если какой-то пункт не сошёлся — скажи прямо, что именно и почему, не пиши «готово». Скоуп — только эта секция: соседние секции, доки и чужие стили не трогать.
