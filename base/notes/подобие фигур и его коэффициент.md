две фигуры являются подобными, если одна получается из другой *равномерным* масштабированием **во всех направлениях**. Если *хотя бы одно* направление масштабировано неравномерно - фигуры **не являются** подобными.

Для подобных фигур соотношение любых линейных размеров равно k - коэффициенту подобия
[[коэффициент подобия треугольников]]

Для n-мерных размеров соотношение будет $k^n$, т.е.
Для [[площади фигур|площадей]] - $k^2$
Для объемов - $k^3$
