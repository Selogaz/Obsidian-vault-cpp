При возобновлении после достижения лимита сессии воркфлоу БУДЕТ ЗАПУСКАТЬСЯ ЗАНОВО: resume (`resumeFromRunId`) работает только внутри той сессии, где воркфлоу был запущен. В новой сессии состояния прошлого рана нет, поэтому фраза «продолжи прошлый воркфлоу» ничего не находит и всё стартует с нуля.

Workaround — не хранить прогресс в воркфлоу: агент по ходу работы дописывает находки и статус в файлы репозитория (чекпоинты), а промт первым действием читает прогресс-файл. Тогда продолжение работает из любой сессии и любой моделью.
