Маршрут: РФ → Армения (2–4 года: доход, диплом, английский, накопления) → Новая Зеландия через образование → Green List → резидентство. Горизонт ~5 лет. Главный рычаг — не страна, а рост дохода: при $600/мес накопления = 0, а НЗ-этап стоит $30–55k на двоих.

Драйвер срочности — [[реестр повесток и автоматический запрет на выезд]]: статус «в запасе» значит, что риск не призыв, а мобилизация/сборы — окно есть, но закрывается одномоментно. Кирилл (Минск) не вариант — [[Беларусь как маршрут эмиграции из России]] исключает Беларусь и как убежище, и как транзит: бесплатное жильё там не экономит деньги, а тратит время. Первая страна — Армения, как и в [[эмиграция из России во избежание мобилизации]].

## Траектория

```
2026 H2   Подготовка в РФ → переезд в Армению
2027–2029 Армения: доход ↑, заочный бакалавриат, IELTS, накопления
2030–2031 НЗ: учёба 1–1.5 года → Post Study Work Visa (партнёр работает full-time)
2031+     Software Engineer → Green List Tier 1 → Straight to Residence
```

## Этап 0 — сейчас, из РФ (июль → ~ноябрь 2026)

[[микрошаги этапа 0 — по одному в неделю]]

Критический путь — **загранпаспорта обоим, подать немедленно** (1–3 мес, самое узкое место по времени). В Армению можно по внутреннему — это аварийный выход, но IELTS, виза НЗ и банки требуют загран.

Параллельно:

1. **Документы об образовании**: академсправка из старого вуза, аттестат, апостиль на аттестат до отъезда (из-за границы — мучительно). Нужно и для поступления, и для NZQA.
2. **Подушка $2–3k минимум** — иначе кассовый разрыв даже в Гюмри. Наличные USD + USDT (лимит вывоза — $10k на человека).
3. **Evidence партнёрства — копить с сегодня**: для партнёрской визы НЗ нужно 12+ месяцев доказательств совместной жизни (аренда, общие счета, билеты, фото с датами). Самая частая причина отказов. Брак не обязателен, но упрощает пакет.
4. **Воинский учёт**: проверять реестр раз в неделю; при выезде >6 мес — сняться с учёта (процедура — «Идите лесом» / «Школа призывника»).
5. **Аварийный чек-лист**: документы в одной папке, наличные, USDT, список рейсов. Триггеры выезда в 48 ч по внутреннему: повестка в реестре, объявление мобилизации, признаки закрытия границ. План при этом не отменяется — этап 0 просто обрывается досрочно.

## Этап 1 — Армения: легализация (1–3 месяца)

- Приземлиться в Ереване, жить в **Гюмри/Ванадзоре**: пара ~$600–700/мес против $1200–1500 в Ереване. Разница — это и есть норма накопления на старте.
- По порядку: регистрация (30 дней) → **ИП с IT-льготой 1%** → ВНЖ на основании ИП (безвиз 180 дн/год — мало, ВНЖ обязателен) → банк (Unibank, IDBank, Ardshinbank) + Payoneer.
- Налоги РФ: уведомить ФНС о счёте в течение месяца. Российского работодателя перевести на договор с армянским ИП (зарплата дистанционщика у работодателя РФ облагается НДФЛ независимо от резидентства; иностранный доход нерезидента не облагается).

## Этап 2 — три параллельных трека (2027 → 2029/30)

**А. Доход — главный.** По годовому плану карьерного развития: тесты, бэкенд, английский, самопродажа. Ориентиры: $1.2–1.5k/мес к концу 2027, $2.5–3.5k/мес к 2029. Партнёр в Армении работает без разрешений (ЕАЭС) — второй доход двигает сроки.

**Б. Бакалавриат.** Для НЗ подходит любой законченный аккредитованный, в т.ч. заочный (NZQA оценивает аккредитованные вузы; «онлайн-only» — нет). Варианты, выяснить в первые месяцы:
- ЕГЭ в школе при посольстве РФ в Ереване (регистрация до ~1 февраля; проверить, что пункт действует) → российская заочка/дистант из-за границы;
- **РАУ**: русскоязычный, двойной диплом, заочно ~$2000/год, свои вступительные — возможно, ЕГЭ не понадобится вовсе;
- запасной: узбекский дистант ($430–970/год).
Академсправка → перезачёт может срезать 1–1.5 года. Реалистично диплом — 2030–2031.

**В. Английский.** B1 → IELTS Academic 6.0–6.5 (магистратура 6.5, grad dip 6.0). Сдача в Ереване, ~$250, за год до подачи. Заодно снимает главный карьерный дисконт.

Цель накоплений: **$30–55k** к подаче. При $1.5k/мес с 2028 нижняя граница — к 2030.

## Этап 3 — подача в НЗ

Развилка по деньгам (правила НЗ менялись 4 раза за 2025–2026 — решать по правилам того года):

| | A: Graduate Diploma IT (L7, 1 год) | B: Master IT (L9, 1–1.5 года) |
|---|---|---|
| Обучение | ~NZD 19–27k (политехи) | ~NZD 40–62k |
| Показать средств всего* | ~NZD 50k ≈ **$30k** | ~NZD 75–90k ≈ **$45–55k** |
| Партнёру open work visa | ⚠️ только если квалификация в Green List/PSWV-списке | ✅ всегда |
| Post Study Work Visa | с 16.11.2026 grad dip даёт PSWV (перепроверить) | ✅ 3 года |

\* обучение + NZD 20k/год на жизнь + NZD 4 200 на партнёра + ~NZD 3k сборы/билеты/страховки.

- Регионы дешевле Окленда: Данидин (Otago Polytechnic, grad dip NZD 23–27k), Гамильтон, Палмерстон-Норт.
- Оплата и подтверждение средств — с армянских счетов (платежи из РФ банки НЗ часто не принимают); копить на счёт ИП, история средств должна быть документированной.
- В НЗ: студент 25 ч/нед + full-time на каникулах; партнёр (вариант B) — full-time. Вдвоём покрывает 60–80% жизни.
- Перед подачей — licensed immigration adviser (IAA): профиль «пара из РФ» не самый простой для genuine student.

## Этап 4 — от учёбы к резидентству

Учёба → **PSWV** (3 года при магистратуре; одна на всю жизнь — не тратить на мелкую квалификацию) → **Software Engineer / Developer Programmer** у accredited employer = **Green List Tier 1 без зарплатного порога** → Straight to Residence (возраст ≤55). Запасной путь — Skilled Migrant Category, 6 баллов. Через 2 года — Permanent Resident.

## Параллельная ветка, которая может обогнать образование

К 2030 будет 5+ лет коммерческого опыта. Software Engineer — Green List Tier 1: job offer от аккредитованного работодателя НЗ из-за рубежа → Straight to Residence **без учёбы и без $50k**. С 2029 параллельно пробовать прямой найм; что сработает первым — то и путь. Треки не конфликтуют: обоим нужны те же диплом, английский, опыт.

## Риски

| Риск | Контрмера |
|---|---|
| Мобилизация до отъезда | Аварийный чек-лист; въезд в Армению по внутреннему |
| Загран затягивают | Подать сейчас; аварийно — загран через консульство РФ в Ереване |
| Армения ужесточит правила | Запасные: Узбекистан (1%, дешёвый дистант, безвиз), Сербия (теперь 90/180 — сразу ИП+boravak) |
| Правила НЗ изменятся | Пересверка перед каждым этапом; ближайшие реформы: 24.08.2026 (SMC), 16.11.2026 (PSWV) |
| Отказ в студвизе НЗ | Чистая история средств, IAA-консультант, крепкий пакет партнёрства |
| Заочный диплом не признают | Государственный аккредитованный вуз; предзапрос в NZQA (IQA NZ$445, ~10 недель) |
| Доход не растёт | Единственный риск, убивающий план целиком. Чекпоинт раз в полгода: нет $1.2k/мес к концу 2027 → пересмотр сроков, не цели |

## Первые 5 действий (эта неделя)

1. Подать на загранпаспорта — обоим.
2. Академсправка из старого вуза; аттестат, план апостиля.
3. Проверить реестр повесток; написать «Идите лесом» про снятие с учёта.
4. Завести папку evidence партнёрства.
5. Выяснить: пункт ЕГЭ в Ереване и правила приёма РАУ на заочку — возможно, ЕГЭ не нужен вовсе (минус год подготовки).

Все цифры — июль 2026; перед каждым этапом пересверять первоисточники: immigration.govt.nz, nzqa.govt.nz, сайты политехов, армянские правила ИП/ВНЖ.
