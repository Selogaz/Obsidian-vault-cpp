После ухода Fable 5 выбор стоит между Sonnet 5 и Opus 4.8. Опорное правило: качество результата определяет промт с циклом верификации, а не модель ([[чем определяется качество верстки]]) — поэтому по умолчанию Sonnet 5, Opus — точечно.

| Задача | Модель | Режим |
|---|---|---|
| Верстка по макету со строгим промтом | Sonnet 5 | effort xhigh |
| Имплементация по готовой спеке/плану | Sonnet 5 | effort xhigh |
| Тесты | Sonnet 5 | effort xhigh |
| Дебаг с воспроизводимым репро | Sonnet 5 | effort xhigh |
| План сложной фичи, архитектурный выбор | Opus 4.8 | plan mode |
| Ревью кода, вердикты по находкам | Opus 4.8 | короткие сессии |
| Неоднозначный дизайн без точного макета | Opus 4.8 | — |
| Интерактив, много мелких правок подряд | Opus 4.8 | /fast |

Правила под Pro-лимиты:

- Длинная многоитерационная работа (верстка со скриншотами, батчи ревью) — всегда Sonnet 5: в разы дешевле по лимиту, а со строгим промтом не уступает.
- Opus — только короткие сессии-суждения: составить план, вынести вердикт по backlog, разрулить неоднозначность. Получил суждение → `/model` → дальше на Sonnet.
- `/fast` не меняет модель (это Opus с быстрым выводом) — для интерактивной работы, не для экономии лимита.
- effort у Sonnet 5 держать xhigh (дефолт Claude Code): понижение экономит мало, а качество роняет заметно.

Детальный разбор для верстки: [[sonnet vs opus]].
