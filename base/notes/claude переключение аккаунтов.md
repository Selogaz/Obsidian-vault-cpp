команды для добавления:
ЗАЛОГИНИТЬСЯ в свой аккаунт, **затем**:
```zsh
cswap add
```

команды переключения существующих:
```zsh
cswap switch
```

запуск отдельной сессии определенного аккаунта
```zsh
cswap run user@example.com
```
