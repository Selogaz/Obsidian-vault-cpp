Класс в геймифицированном рейтинге чата «Эхо бездны» — это **не уровень, качающийся по прямой, а пара из двух осей, в которых у участника больше всего «деяний»**[^1]. Осей шесть; класс называется по двум ведущим.

- Текущий класс **«Редактор» = Ясность + Вопрос** (значит, больше всего деяний в этих осях).
- Цель **«Архитектор» = Глубина + Инженерия**.

Чтобы стать Архитектором, нужно набрать столько деяний по Глубине и Инженерии, чтобы эта пара обошла Ясность + Вопрос как две топовые оси.

## Шесть осей и пороги деяния

| Ось | Что засчитывает | Порог деяния |
|-|-|-|
| **Глубина** (depth) | глубокий разбор, инсайт, обоснованная критика — мысль по существу | 18 |
| **Инженерия** (tech) | код, архитектура, отладка, техническое решение | 20 |
| Ясность (clarity) | просто и понятно объяснить сложное | 12 |
| Вопрос (question) | толковый конкретный вопрос, сдвигающий разговор | 20 |
| Помощь (help) | чужой вопрос получил рабочий ответ (закрытие вопроса) | 20 |
| Катализатор (catalyst) | сообщение стало корнем оживлённого треда | 30 |

## Как начисляется деяние

`Баллы = качество × отклик`. Деяние в оси фиксируется, когда баллы **одного сообщения** в оси перешагивают её порог **И** у сообщения есть хотя бы один содержательный отклик (чат подтверждает оценку AI).

- **Качество** (оценка AI 3–5 → базовые очки): 3 → 5, 4 → 12, 5 → **25**. У Ясности своя скромная шкала (4 → 6, 5 → 14). **+5 к Инженерии за код** в сообщении.
- **Две оси на сообщение:** база идёт максимум в две оси — в главную полностью, во вторую с коэффициентом **×0.5** (иначе классы схлопнулись бы в один).
- **Отклик умножает базу:** содержательный ответ ×0.25 (первые ответившие ценнее), уникальный эмодзи +0.05 (потолок ×10), анонимные реакции ×0.5.
- **Ступени I–V** внутри класса: 3 / 8 / 20 / 45 / 100 деяний, никогда не падают.

## Стратегия перехода Редактор → Архитектор

1. **Смести содержание в Глубину + Инженерию:** код / архитектура / разбор отладки и глубокий анализ с инсайтом или аргументированной критикой. Целевая оценка AI — **5** (25 очков сразу перекрывают оба порога).
2. **Сильнейший ход — сообщение, мощное сразу в обеих осях:** рабочее решение с кодом + содержательное обоснование архитектуры. Одно такое сообщение может дать деяние и по Глубине, и по Инженерии. Но вторая ось идёт ×0.5 — чтобы пробить и её порог, нужен небольшой отклик. Надёжная альтернатива — чередовать чистый разбор и чистую инженерию.
3. **Добивайся отклика:** без хотя бы одного содержательного ответа деяние не засчитается, а ответы/реакции умножают баллы. Пиши в активное время.
4. **Это марафон:** показанный класс меняется, только когда новая пара **уверенно и дважды подряд** обгоняет прежнюю. Старые деяния по Ясности/Вопросу **не сгорают** — их нельзя убрать, можно только перерасти. Нужен устойчивый перевес.

> [!warning] Подводные камни
> - Каждый новый «толковый вопрос» и «простое объяснение» защищает старую пару (Редактор) — осознанно снижай их долю.
> - **Не растекайся по всем шести осям:** при ≥6 деяниях без доминирующей оси (доля любой < 25%) присвоят «Универсала», а не Архитектора. Глубина + Инженерия должны именно доминировать.
> - Задним числом не накрутить: отклик считается по базе на момент отклика — дописать старое сообщение и собрать прошлые реакции не выйдет.

[^1]: Правила выведены из API движка (`/api/scoring-model`) и JS-бандла приложения [Эхо бездны](https://echo.brainysnipe.ru/#/help), т.к. страница помощи рендерится через JavaScript. Числа — те же, что использует сам движок (по состоянию на 2026-07-21).
