Рабочая версия этапа 0 из [[план переезда в Новую Зеландию через Армению]] — размолотая до шагов, каждый из которых можно сделать за один подход без подготовки и настроя.

**Правила.** Один шаг в неделю — этого достаточно: этап 0 рассчитан до ноября, запас есть. Никакой шаг ничего не решает и ни к чему не обязывает — загран полезен в любом сценарии жизни. Если на неделе сил нет совсем — сделать только «нулевой» шаг (2 минуты) и это считается.

## Нулевой шаг (2 мин, всегда доступен)

- [x] Проверить себя в реестре повесток. Пусто → всё в порядке, окно открыто, спешить некуда. ✅ 2026-07-18

Как: реестрповесток.рф → «Войти в личный кабинет» → авторизация через Госуслуги → видно, есть ли повестки на твоё имя; кнопка «Запросить выписку» даёт официальную выписку за ~5 минут. Сайт требует ГОСТ-шифрование — открывать из Яндекс Браузера (Chromium GOST тоже подходит). Проверка безопасна: повестка считается вручённой по факту размещения в реестре / через 7 дней — независимо от того, смотрел ты её или нет, так что просмотр ничего не запускает и не ускоряет, а только даёт знание. Заодно глянуть уведомления на самих Госуслугах.

## Шаги по ≤15 минут (с дивана, Госуслуги)

- [ ] Начать заявление на загран на Госуслугах — просто открыть форму и заполнить первую страницу. Можно бросить на середине, черновик сохранится.
- [ ] Дозаполнить черновик заявления.
- [ ] Загрузить фото в заявление (можно сфотографироваться у стены на телефон).
- [ ] Оплатить пошлину со скидкой через Госуслуги.
- [ ] То же самое — партнёру (или партнёр делает свою часть сам, параллельно).
- [ ] Написать «Идите лесом» один вопрос: как правильно сняться с воинского учёта при выезде >6 мес. Официальный бот помощи: `@iditelesom_info_bot`, канал: `@iditelesom_help` (сверено с iditelesom.org — сайт открывается только с VPN; база знаний без VPN: iditelesombase.org). Хэндл сверять посимвольно, помощь у них бесплатная — просьба денег/данных карты = клон-скам.

## Шаги по ≤30 минут

- [ ] Завести папку «партнёрство» (физическую или в облаке) и положить туда первый документ — договор аренды или пару общих платежей.
- [ ] Написать в деканат старого вуза запрос на академическую справку (одно письмо, шаблон попросить у Claude).
- [ ] Спросить в РАУ (одно письмо в приёмную): правила поступления на заочку для граждан РФ, нужен ли ЕГЭ.

## Шаги-визиты (по записи, один выход из дома каждый)

- [ ] Визит в МВД по записи с документами на загран — это очередь и окошко, стандартная процедура, миллионы человек в год.
- [ ] Забрать готовый загран.
- [ ] Забрать академсправку (или получить почтой).
