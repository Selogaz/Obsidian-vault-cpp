План писать с помощью [[sonnet vs opus|Opus, не Sonnet]].
Если токенов полно, можно использовать [[стратегия черновик + умный критик]]

План должен содержать:
- сам план задачи
- декомпозицию этой задачи на подзадачи
- для каждой подзадачи своя сессия Sonnet
- для каждой сессии отдельный промпт
- промпты по образцу [[промт для верстки bite-transit(асташко)]] или по файлу `session-prompts.md` в `bite-transit` проекте.
